# GeoReady Documentation

Welcome to the GEO Optimizer technical documentation — the open-source Python
CLI that audits and fixes websites for AI-search visibility.

Get started with your first audit in under five minutes, or browse the sections
in the sidebar: CLI commands, scoring, structured data, infrastructure, and
integration guides.

## Quick start

```bash
pip install geo-optimizer-skill
geo audit --url https://yoursite.com
```

Get a GEO score 0–100 with actionable recommendations, then auto-fix:

```bash
geo fix --url https://yoursite.com --apply
```
